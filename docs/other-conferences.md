# Other conferences

NeurIPS 2026 is bundled. For any other conference you bring its paper list, and the agent imports it once; later questions reuse it. Back to the [README](../README.md).

## A CSV or JSON paper list

The list is a CSV or JSON file with title, authors and abstract (times are optional). Many conferences publish one on the same website software as NeurIPS: on the Downloads page of the conference site (for example `icml.cc/Downloads/2026`), choose csv and press Download Data. Then ask your question, naming the conference and the file:

> I'm going to ICML 2026. Its paper list is `~/Downloads/ICML 2026 Events.csv`. My abstract is: ...

The agent looks at the file, writes a column mapping, and `scripts/import_dataset.py` checks it. The import writes nothing if the file is not good enough (fewer than 50 records, missing titles, abstracts on under half of the papers, conflicting ids, times without a time zone). Otherwise it saves the dataset in `~/.conference-picks/<name>/` (set `CONFERENCE_PICKS_HOME` to move it) and shows a report with three sample records for you to confirm. If you say something is wrong, the agent fixes the mapping and imports again, or deletes the dataset. Later questions reuse it, and `python3 scripts/search.py list` shows what is installed. If the agent cannot write there (a read-only Codex folder, say), it is told to print the mapping and the import command for you to run in your own terminal.

With no times in the file there is no grouping by session and no calendar file; picks are ranked and the answer says so. A dataset comes from one file: if abstracts and times are in different files, join them first. Status, as of 2026-11-11 (version 0.3.6): tested by script on the ICML 2026 CSV and on NeurIPS's raw files. With a Claude agent on the current ICML 2026 file (6,689 events, 17 MB): it imported the file, showed the report and waited for the user's OK, then gave 19 ranked picks, all real ICML posters with their real authors ([the answer](example-answer-icml.md)); a second agent, in a new conversation, found the saved dataset and listed the 73 ICML papers with UT Austin authors. Earlier runs, one each: Claude Code (Sonnet) imported it, gave picks and asked for the file when given none; Codex imported it and gave picks where it could write, and printed the import command where it could not. Not tested: a conference file with session times, file formats other than this CSV, the Claude and ChatGPT chat apps, Windows and Linux.

## A PDF or text book of abstracts

Some conferences publish only a book of abstracts. Give the agent the PDF, or its text, and name the conference; [TEXT_PROGRAMS.md](../plugins/conference-picks/skills/conference-picks/TEXT_PROGRAMS.md) tells it what to do. Supported: a single-column book in which every entry is a title, one marker line (`Presenter: Name`, or `Authors: Name (Affil), ...`) and an abstract, under day, time-block and session headings, with footers and page numbers around. Not supported: two-column layouts, scanned books (there is no OCR), tables, figures, and an author list that wraps over several lines. A PDF needs `pdftotext` from poppler: the importer calls `pdftotext -layout` itself when it is on your PATH, and otherwise prints the command (`pdftotext -layout book.pdf book.txt`) for you to run. It installs nothing.

Parsing runs on your machine and costs no tokens. The extra cost is the agent's own turns, once per book (later questions reuse the saved dataset): a structure summary from `inspect` (under 3 KB), the patterns it writes, a retry if a check refuses, and the import report. Measured with Claude Sonnet on the 193-page test book, one run each: $0.49 for one full run (import and picks, 31 turns, an earlier version of the instructions); with the final instructions, $0.25 for the import and report, where the agent stops to ask you, plus $0.26 for the picks in a later run that reuses the saved dataset. The ICML CSV took $0.29 for import and picks, so the book route costs about $0.2 more (about 70%), once per book. A different book, agent or wording will differ. The expensive mistake is putting the book itself into the chat: the 193-page test book is 943,438 characters, about 236K tokens at 4 characters per token (an estimate), so give the agent the file's path and do not attach it.

You get title, abstract, presenter or listed authors, day, time block, session and room, and the book page when the offset between printed and PDF page numbers is known. Only the people the book lists are known, and affiliations only if it prints them, so `who --affil` is weak. Times are those of the session or block, not of each talk. Entries are cut out by patterns, so some can come out wrong: on the real book used for testing, at least 6 of 637 titles were wrong. The import refuses a weekday that does not match its date (that book prints two), until you confirm the real date. The patterns are the agent's: in one run its room pattern missed one session heading and left 4 entries wrong, so check the `text:` line of the report (days, blocks and sessions found) as well as the samples. Status, as of 2026-11-11 (version 0.3.6): tested by script on synthetic books. With a Claude agent on the ISBA 2026 World Meeting program (193 pages, 637 entries; the same real book as the earlier runs): it stopped and printed the `pdftotext` command while poppler was not installed, asked for the time zone (the book prints none) and for which of two clashing day headings was right, imported all 637 entries with times, showed the report, and after the user's OK gave 20 picks grouped by day and time, all with the right title, presenter and time ([the answer](example-answer-isba.md)). It also found the user's own poster in the book. It showed one gap, fixed since in 0.3.6: 8 session titles that wrap onto two lines came out as their last line only ("Approaches", "nologies"), with their first line left at the end of the abstract above, and the report did not show it. The importer now joins such a title when its first line stands alone under a blank line or a heading (on that book: all 16 wrapped titles whole, no abstract with a stray line), lists every joined title in the report, and warns about a heading that starts in lowercase right under a line of text. Earlier runs: Claude Sonnet on the same book, five runs. Not tested: Codex, the Claude and ChatGPT chat apps, a second real book, and the Authors layout on a real book.
